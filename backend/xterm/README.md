# Reproducible terminal assets

This component reconstructs the tested backend's `ui/xterm.js` and
`ui/xterm.css` from the pinned `@xterm/xterm` 6.1.0-beta.291 npm archive.
The full upstream MIT notice is included in both generated files and retained
in `LICENSE.txt`. No npm scripts or downloaded JavaScript are executed.

With Python 3.9+, from this directory:

```sh
python3 reconstruct.py --output /absolute/path/to/new-output-directory
```

The tool downloads only the pinned npm archive, with a bounded timeout and size,
and verifies its SHA-256 and npm integrity, package identity, dependency list,
license and source hashes before writing output. Use `--archive /path/to/archive.tgz`
to supply the exact archive offline. An existing output directory is refused.
Choose output outside the checkout.

The only transformations are the original license header and removal of the
JavaScript's final source-map reference. The generated bytes match the tested
backend exactly. The manifest records all input and output hashes.

This source component does not contact or change a ship and is not a complete
backend installer. See [compatibility](../../docs/COMPATIBILITY.md).
